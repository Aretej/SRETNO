Udruga SRETNO – Web stranica

Web stranica Udruge SRETNO, izrađena s ciljem predstavljanja udruge, njezine povijesti, aktivnosti i rudarske tradicije. Stranica obuhvaća informacije o događanjima, proslavi Svete Barbare, tradicionalnom običaju Skoka preko kože te galeriju fotografija.

Projekt je izrađen pomoću HTML-a, CSS-a i JavaScripta, s responzivnim dizajnom prilagođenim računalima, tabletima i mobilnim uređajima.

Hosting: GitHub Pages.
